# Copiloto WhatsApp MD Marketing

Extensao Chrome gratuita para usar a IA SDR dentro do WhatsApp Web.

## O que ela faz

- Abre um painel lateral no WhatsApp Web.
- Le o texto visivel da conversa.
- Envia esse contexto para a API do app IA SDR.
- Gera uma resposta consultiva.
- Copia ou preenche o campo de mensagem.

## Limite importante

Ela nao aperta enviar automaticamente. Isso evita risco de disparo sem revisao e mantem o fluxo sem API paga.

## Como instalar no Chrome

1. Abra `chrome://extensions`.
2. Ative `Modo do desenvolvedor`.
3. Clique em `Carregar sem compactacao`.
4. Selecione a pasta:

```txt
C:\Users\somas\OneDrive\Documentos\CODEX\ia-sdr-md-marketing\chrome-extension
```

5. Abra `https://web.whatsapp.com`.
6. Clique no botao `MD Copiloto`.

## Como usar

1. Entre em uma conversa no WhatsApp Web.
2. Clique em `MD Copiloto`.
3. Clique em `Ler conversa`.
4. Clique em `Gerar resposta`.
5. Clique em `Preencher WhatsApp`.
6. Revise e envie.
